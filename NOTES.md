## Design rules

- `comfy.py` is the only module that talks to ComfyUI. `comfy.stop` is the stop signal; `comfy.run` returns a `Result` (success | error | cancelled | timeout).
- The text model only returns labels (line numbers, a genre name, sentence numbers). It never writes article text. Every use has a fallback.
- A job's body is plain text: one paragraph per line, block quotes indented four spaces. Title, author and site are separate columns. Pronunciations are applied at read time, not at fetch.
- Resume works by a signature (hash of text, voice, engine and the settings that shape the audio) stored with the plan in `data\work\<job>\plan.json`. Same signature: reuse plan and finished segments. Anything changed: start over. Don't re-plan on resume, the text model is not deterministic.
- `llm.loaded` tracks whether the text model is in ComfyUI's memory; whoever needs the memory next frees it.
- Settings: `settings.json` holds only overrides; unknown keys are an error on load (that is deliberate, it catches typos).

## Gotchas

- Bash heredocs in this environment collapse `\\` to `\` (so `'\\n'` becomes a real newline inside a string). Write Python helpers with the Write tool, or use Edit, instead of `python - <<EOF` when the code has backslashes.
- `/tmp` paths from Git Bash are not visible to Windows Python; use the session scratchpad.
- `python` on PATH is system Python 3.10. Whisper runs under ComfyUI's venv Python (`asr_worker.py`).
- The Breeze node pack needs the local PR #15 patch (`_combined_linear = None`); a `git pull` there can undo it.
- The app's console output is block-buffered when redirected; use `python -u`.
- Two apps listen locally: Article2Pod on 8080 and YTunes on 8090. Check the command line before stopping a process.
- `textclean.py` is a wholesale copy of the old site/title/author heuristics; it reads settings through `_cfg()`. Treat it as hard-won and change it carefully.
- Packages installed into system Python for this work: `trafilatura`, `pytest`, `pyflakes`.
